Понедельный ряд финансового эффекта

Сформировано 2026-09-18 15:18 · версия ITT-U-2026-09-18-v16-ult

Кумулятивные срезы на текущих платежах витрины; ретроспектива ≠ архивный снимок на ту дату. Вклад отдельного убытка в Δ ITT — диагностическая оценка без стратификации по филиалам.

Стартовое окно пилота → week_end (кумулятивно). Частота: W-SUN + финальный as_of.

Общая логика ряда
Срез week_end: инциденты с ДатаЗаявления ≤ week_end, t_calc = week_end
Yult = paid + NPV(хвост ПСР); paid = Σ СуммаПлатежа из текущей витрины (не архив платежей на ту дату)
ITT(H) = Σf wf·(ȲH(control,f) − ȲH(model,f)), wf = Nf/Σ Ng
Плюс ITT = control дороже model = экономия модели.

Пояснения

  • Платежи на всех срезах — из одной текущей выгрузки витрины: прошлые недели могут «пересчитаться», если СуммаПлатежа дописалась.

Куда уехали control и model

Связь средних групп и Δ ITT
ITT ≈ mean(control) − mean(model) (здесь без стратификации по филиалам)
Δmean_control = mean_control(week) − mean_control(prev)
Δmean_model = mean_model(week) − mean_model(prev)
itt_contrib_control = Δmean_control
itt_contrib_model = −Δmean_model
delta_itt_unstratified = itt_contrib_control + itt_contrib_model
Если model подешевел (Δmean_model < 0), вклад model в Δ ITT положительный: −(отрицательное) = плюс. Это не «ошибка знака».

Пример: mean_model 142k → 131k ⇒ Δmean_m = −11k ⇒ вклад m = −(−11k) = +11k

Как считается

Пример new control Yult=400, mean_prev=100, N_prev=2: pull = +1×(400−100)/3 = +100
Пример payment_update model Δpaid=−60, N=2: pull = −1×(−60)/2 = +30
