Запрос POST /api/predict

Тело — схема ServiceRequest (mldataworker). Вектор — список из одного объекта (одна заявка).

ПолеТипОбязательноСмысл
main_model string да stem файла <stem>.pickle legacy-ансамбля (clf+rg)
main_request object[] да единичный вектор признаков для main_
second_model string | null нет stem pickle 2.0.0; без него second_response = {}
second_request object[] | null нет вектор для second_; FE_* сервис считает сам

main_ — ключевые признаки

После preprocess должны быть колонки clf/rg (порядок важен для mldataworker).

Classification:
FILIAL, EVENT_CREATED_BY_GIBDD_FLAG, VICTIM_MAX_WEIGHT, RECIEVE_METHOD, APPLICANT_FORM, APPLICANT_AGE, VICTIM_VEHICLE_CATEGORY, GUILTY_CAPACITY_ENGINE, VICTIM_VEHICLE_AGE, EVENT_YEAR

Regression:
AMOUNT_REPAIR, LOSS_UNIT_ZONE, VICTIM_VEHICLE_COUNTRY, APPLY_DELAY

THRESHOLD во входе (опционально) → порог CF; иначе default 0.6. IS_LAWYER влияет на маску итога.

second_ — отличия

  • Список фич берётся из model_config pickle 2.0.0
  • В запросе нет готовых FE_* — их строит сервис (CPI REAL_2022, SHARE_WORK tier, …)
  • CF/RG калибраторы; τ из THRESHOLD в векторе, иначе config fallback
  • Clip — из feature.clip в pickle, не отдельный dq_bounds

Ответ 200 OK

{ "main_response": { … }, // legacy · version из MAIN_VERSION "second_response": { … } // 2.0.0 или {} }

main_response

{ "usage_model": "<main_model>", "version": "1.4.0", "CPMComment": "shap_clf: … | shap_reg: …", "result": { "classification_proba": […], "classification_predictions": […], "regression_predictions": […], "prediction": […], "threshold": 0.55 }, "df": { "input": [ { …preprocess… } ], "output": [ { …матрицы clf+reg… } ] } }

second_response

Та же форма, что main_response; version из SECOND_VERSION (по умолчанию 2.0.0).

{ "usage_model": "<second_model>", "version": "2.0.0", "CPMComment": "shap_clf: … | shap_reg: …", "result": { "classification_proba": […], "classification_predictions": […], "regression_predictions": […], "prediction": […], "threshold": 0.42 }, "df": { "input": […], "output": […] } }

Маска итога IS_LAWYER

  • По умолчанию: итог = регрессия, если класс = 1, иначе 0
  • Если IS_LAWYER == 1: всегда значение регрессии (даже при классе 0)
  • Одинаковая логика для main_ и second_
