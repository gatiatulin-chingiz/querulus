TARGET_FREQ / TARGET_SEV: источники, фильтры, джойны.

Выжимка Сборка Таргеты

Выжимка

  • Модель. На инцидент: TARGET_FREQ (0/1 — будет ли доплата после первичного УУ) и TARGET_SEV (сумма доплаты, ₽).
  • Зерно. Одна строка = один инцидент. Если в инциденте несколько убытков, в каркас берётся убыток с наименьшим номером.
  • Метка. По каждому иску — сумма с последней принятой инстанции; по претензиям — доплаты с ответом «Выплата» / «Частичная выплата». Freq = сумма по искам и претензиям > 0; Sev = эта сумма в рублях.

Сборка df (источники, JOIN, WHERE)

1. Каркас строк

FROM df_victim
LEFT JOIN (
    SELECT LossNumber, VictimObjectType, RefundFormByPaymentOrder
    FROM OISUU_report.dbo.oisuu81_t_Losses
    WHERE InsuranceTypeGroup = 'ОСАГО'
      AND LossProcess IN (
            'Прямое ОСАГО (с 1 марта 2009)',
            'Традиционное ОСАГО'
          )
      AND Risk = 'Ущерб имуществу третьих лиц'
) df_loss_object_types
  ON df_victim.LOSS_NUMBER = df_loss_object_types.LossNumber

WHERE df_victim.REFUND_FORM_DETAILED IN (
        'Ремонт',
        'Денежная',
        'Денежная. Отказ от ремонта',
        'Ремонт. Смена СТОА'
      )
  AND df_victim.PAYMENT_ORDER_DATE_TIME >= '2020-01-01'
  AND df_victim.PAYMENT_ORDER_DATE_TIME <= '2025-06-30'
  AND df_victim.LOSS_PROCESS IN (
        'Прямое ОСАГО (с 1 марта 2009)',
        'Традиционное ОСАГО'
      )
  AND df_victim.RISK = 'Ущерб имуществу третьих лиц'
  AND df_loss_object_types.VictimObjectType = 'Автотранспорт'
  AND VICTIM_POLICYHOLDER_TYPE = 'Физ. Лицо'
  • На инцидент оставляем одну строку: сортировка по номеру убытка по возрастанию, берём первую (первичный / минимальный убыток).
  • VICTIM_POLICYHOLDER_TYPE = 'Физ. Лицо' — тип страхователя потерпевшего (поле из victim). Не заявитель и не виновник. Юрлица и прочие типы отсекаются целиком.

2. Калькуляция / износ — oisuu81.dbo._InfoRg14746

Не таргет: признаки ремонта и износа на инцидент (AMOUNT_REPAIR, SHARE_WORK, SHARE_WEAROUT). 

FROM oisuu81.dbo._InfoRg14746 AS i
LEFT JOIN OISUU_report.dbo.oisuu81_t_Losses AS l
  ON l.LossID = i._Fld14747RRef
LEFT JOIN OISUU_report.dbo.oisuu81_t_IncidentToLoss AS itl
  ON l.LossID = itl.LossID

WHERE YEAR(l.IssueDate) IS NOT NULL
  AND l.LossProcess IN (
        'Прямое ОСАГО (с 1 марта 2009)',
        'Традиционное ОСАГО'
      )
  AND l.Risk = 'Ущерб имуществу третьих лиц'

-- на инцидент одна строка:
--   ORDER BY LossNumber DESC, _Period DESC → берём первую
--   (последний убыток инцидента + последний период расчёта)
  • Из регистра: сумма ремонта без износа, стоимость запчастей, работы, материалы, процент износа, стоимость с учётом износа, пробег, дата начала эксплуатации и др.
  • После выгрузки: процент износа выше 50 обрезается до 50; SHARE_WORK = работы / сумма ремонта без износа; в df уходят AMOUNT_REPAIR, SHARE_WORK, SHARE_WEAROUT (LEFT JOIN к каркасу по номеру инцидента).
  • Важно: каркас строк — убыток с минимальным номером; калькуляция — с максимального убытка инцидента.

3. Иски → суммы на инцидент

FROM OISUU_report.Datamart.oisuu81_t_IncomingClaimNewLogicByInst AS icnl
LEFT JOIN OISUU_report.dbo.oisuu81_t_IncidentToLoss AS itl
  ON itl.LossNumber = icnl.LinkLossNumber
LEFT JOIN OISUU_report.dbo.oisuu81_t_Losses AS l
  ON l.LossNumber = itl.LossNumber

WHERE (icnl.ClaimOrigin IN ('ВСК', 'Обращение к ФУ') OR icnl.ClaimOrigin IS NULL)
  AND (icnl.ClaimItem NOT IN ('ВСК - 3 лицо') OR icnl.ClaimItem IS NULL)
  AND l.LossProcess IN (
        'Прямое ОСАГО (с 1 марта 2009)',
        'Традиционное ОСАГО'
      )
  • ClaimOrigin IS NULL — иски без заполненного происхождения не отбрасываем; в выборку попадают и «ВСК» / «Обращение к ФУ», и пустое значение.
  • Отсев пустых инстанций. Не берём строку, если решение = «не принято», либо одновременно пусты (не заполнены) все суммы взыскания: взыскано с госпошлиной, основной долг, износ, УТС.
  • Какая инстанция у иска. У одного иска несколько инстанций во времени. Берём одну строку на пару (номер убытка, номер иска): сортируем по дате периода заявленных требований (ClaimedValuePeriod) и оставляем самую позднюю принятую — это финальный исход иска для метки, а не промежуточный.
  • Финансовый уполномоченный (ФУ). Строка считается ФУ, если номер инстанции в ОИСУУ = 6, или номер = 1 и происхождение иска = «Обращение к ФУ» (в первой инстанции ФУ помечается через происхождение, не только через код 6). ФУ — досудебная стадия: если по этому иску уже есть хотя бы одна принятая судебная инстанция (коды 1–5, кроме строк ФУ выше), сумму с ФУ не берём — берём суд.
  • Сумма на инцидент. После выбора одной инстанции на каждый иск: сначала складываем суммы исков внутри одного убытка, затем складываем по всем убыткам инцидента. Для частоты — поле «взыскано с госпошлиной»; для тяжести — основной долг + износ + УТС.

4. Претензии → доплаты на инцидент

FROM OISUU_report.dbo.oisuu81_t_Pretensions AS p
LEFT JOIN OISUU_report.dbo.oisuu81_t_IncidentToLoss AS itl
  ON p.LossID = itl.LossID

WHERE p.InsuranceTypeGroups = 'ОСАГО'
  AND p.AnswerType IN ('Выплата', 'Частичная выплата')
  • После соединения с инцидентом одна претензия может дать несколько строк (несколько убытков). Сначала на пару (инцидент, номер претензии) берём максимум доплаты и доплаты УТС — чтобы не удвоить одну претензию. Затем по инциденту складываем доплаты разных претензий.

5. Склейка в итоговый df

FROM df
LEFT JOIN df_calc_agg
  ON df.INCIDENT_NUMBER = df_calc_agg.INCIDENT_NUMBER
LEFT JOIN claims_by_incident
  ON df.INCIDENT_NUMBER = claims_by_incident.INCIDENT_NUMBER
LEFT JOIN pretensions_by_incident
  ON df.INCIDENT_NUMBER = pretensions_by_incident.INCIDENT_NUMBER

TARGET_FREQ / TARGET_SEV

ТаргетФормула
TARGET_FREQ 1, если сумма «взыскано с госпошлиной» по выбранным инстанциям исков плюс доплаты претензий (включая УТС) > 0; иначе 0
TARGET_SEV сумма по искам (основной долг + износ + УТС с выбранных инстанций) плюс доплаты претензий (включая УТС), ₽
